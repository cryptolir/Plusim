# Archive — historical (Havaya era)

These documents are kept for history only. Plusim was seeded from the **Havaya**
codebase (a life-coaching chat app on the AgentGlob agent `life`, at
`app.havaya.me`), and the files below are that project's planning, QA, and
AgentGlob-integration notes. They describe the *old* product and app domain and
may reference `life`, `app.havaya.me`, `/journey`, YouTube sections, and other
surfaces that do **not** exist in Plusim.

**Do not treat anything here as current.** The live state of Plusim is the code
plus the active docs at the repo root and in `docs/`:

- `README.md`, `PLAN.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `DEPLOY.md`
- `docs/REPORTS_PIPELINE.md`, `docs/DRIVE_INTEGRATION.md`
- `docs/plans/` — active plans
